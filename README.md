# Developer Portfolio - Bharthraj

Modern, lightweight, responsive portfolio website built with HTML5, CSS3, and JavaScript.

## Features
- 🌙 **Dark/Light Mode Toggle** with smooth transitions and persistence
- 📱 **Fully Responsive Layout** for Desktop, Tablet, and Mobile
- ⚡ **Interactive Code Card** and Dynamic Components
- 📂 **Project Showcase** and Technology Badges
- 📩 **Contact Form** with interactive feedback

## Local Setup
Simply open `index.html` in your web browser or run a simple HTTP server:

```bash
python -m http.server 8000
```
Navigate to `http://localhost:8000` to view the site.
