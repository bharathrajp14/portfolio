# Bharath Raj P — Portfolio

A responsive developer portfolio for **Bharath Raj P**, focused on backend systems, AI runtimes, secure product workflows, and evidence-led project storytelling.

## Highlights

The site uses a Field Notes editorial design system: a BRP identity rail, numbered sections, a warm paper canvas, mineral-green structural accents, four selected case studies, and a complete expandable archive of the public GitHub portfolio.

The portfolio content is grounded in Bharath's resume and repository analysis. The featured projects are BR JARVIS, NEXORA, Farmaa, and JobBoard Pro. A detailed audit and content strategy is available in [`portfolio-analysis.md`](./portfolio-analysis.md).

## Local development

Install dependencies and start the Vite development server:

```bash
pnpm install
pnpm dev
```

Run the static type check and production build before publishing changes:

```bash
pnpm run check
pnpm run build
```

## Technology

The codebase uses React 19, TypeScript, Vite, Tailwind CSS, and Lucide icons. Visual assets are hosted through the associated portfolio project and are referenced from the application as persistent asset paths.

## Project integrity

Do not replace project claims with vague marketing copy. New case studies should make the problem, implementation decision, and verifiable proof explicit. Use real screenshots, deployment links, tests, or architecture diagrams whenever available.
